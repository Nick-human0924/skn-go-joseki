# skn-go-joseki

一个给孩子使用的围棋定式记忆训练工具。它的重点不是展示大量复杂棋谱信息，而是帮助家长或老师把孩子不会的定式拆成可以反复练习的小题。

## 项目目标

- 为孩子定制化记录不会的定式和变化。
- 让孩子在一个安静、清晰的页面里反复练习。
- 把棋盘作为页面中心，减少复杂信息干扰。
- 支持打印练习页，让孩子可以在线下填写手顺。

## 功能概览

- 支持 9 路、13 路、19 路和自定义棋盘大小。
- 支持分类、标签和定式变形管理。
- 支持黑棋、白棋、答案点和橡皮编辑工具。
- 支持从某一步开始记录答案手顺。
- 支持顺序填空和自由落子两种练习方式。
- 支持每步提示和练完再判两种批改方式。
- 支持手顺列表查看、选中高亮、改色和删除。
- 支持为整个定式库建立备份，并在误删后整库恢复到备份版本。
- 支持本地浏览器保存、JSON 导入导出。
- 支持配置 Supabase 后用邮箱密码登录，并把整份定式数据同步到账号。
- 支持打印练习页、答案页、练习加答案页，并保留最近打印记录。

## 使用方式

这个项目是纯静态网页，不需要安装依赖。

1. 下载或克隆仓库。
2. 直接用浏览器打开 `index.html`。
3. 在左侧选择分类或新建分类。
4. 在中间编辑定式和答案手顺。
5. 在右侧选择练习方式开始训练。

## 适合场景

- 家长给孩子整理最近下棋中反复出错的定式。
- 老师按阶段给学生准备定式复习题。
- 孩子通过网页练习或打印题纸记忆手顺。

## 数据说明

所有数据默认保存在当前浏览器的本地存储中，不需要账号登录，也不会上传到服务器。需要换设备时，可以用 JSON 导出和导入。

如果要开启账号云同步：

1. 当前已配置 Supabase 项目 `ovsmowsqiivdxfptbqte`。
2. 如果更换 Supabase 项目，在 SQL Editor 运行 `supabase/go_joseki_stores.sql`。
3. 如果更换 Supabase 项目，在 `supabase-config.js` 填入新项目 URL 和 publishable key。
4. 重新打开 `index.html`，在右侧“账号同步”里注册或登录。

未登录或 Supabase 未配置时，应用仍然只使用浏览器本地保存。登录后会先读取云端数据；云端没有数据时，会把当前本地数据上传为账号初始数据。

## 设计原则

- 棋盘优先：中间棋盘是最重要的视觉区域。
- 操作简单：编辑和练习状态分离，减少孩子误操作。
- 信息克制：只展示当前练习需要的信息，不把复杂棋谱管理界面暴露给孩子。
- 可打印：方便把定式题变成线下练习纸。
